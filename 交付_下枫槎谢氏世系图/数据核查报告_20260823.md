## 二、两套数据的客观差异

按 ID 对照原始快照：交付版磁盘数据 1,254 条；后台接口数据 1,253 条；相同 ID 1,247 条；交付版独有 7 条；后台独有 6 条；存在字段差异的相同 ID 101 条，其中父系字段差异 96 条、性别字段差异 15 条。

这些差异包含同名人物、入继/出继双记录、用户后来核定的补录人物，以及旧后台仍保留的错误父子线。因此本次前端不采用整表覆盖，而是：

1. 以交付版数据和已写入交付页的谱页核定规则作为展示基线；
2. 后台数据只作对照源，不自动反向覆盖；
3. 同名人物按 ID 保留，亲生记录与入继记录不合并；
4. 无法仅凭抽取文字确认的冲突保持可见，避免猜测父亲造成新的错误。

## 四、性别口径

原始字段不能直接作为最终女性统计口径。当前交付页统计优先采用明确谱页语义（“女一”“长女”“次女”等）校正，并将仍没有可靠性别信息的记录单独计入“性别未标注”，不把未知强行归为男性。人物卡片和查询统计使用同一套性别口径。

特别复核：`保岳`在谱文中明确为“入赘婿”，因此按男性处理；原始字段中的 `gender=女` 已被覆盖，不再计入女性统计。入赘身份与性别是两个独立字段，不能把“入赘”误当作女性或入继。

## 五、入继、出继、入赘的展示规则

- 出继人物保留在亲生父亲支系，并在卡片上显示“出继”；
- 入继记录保留在承嗣父名下，并在卡片上显示“入继”；
- 出继人的后代在树状展示中归到入继记录卡片下，避免出现父系断链；
- 入赘单独统计、单独保留在人物详情和族谱文字中，不把入赘误判为入继；
- 兼祧、入祧、祀子作为独立承嗣/祧继说明保留，不与普通父子关系混写。

## 六、当前交付页新增能力

交付页新增“族谱查询”抽屉，使用图一的纸本档案风格，包含族谱统计、世代时间轴、高级搜索、搜索结果定位高亮、同名人物按 ID 选择、亲缘关系路径查询和数据审查状态。

## 七、仍需人工按原谱最终签字的项目

后台与交付版仍有 101 条字段差异。前端已经把差异作为审查状态展示，但没有把后台旧数据强行并入当前树面。要达到最终归档版，建议下一步在查询面板增加逐条审核表：每条冲突显示交付值、后台值、谱页页码和审核人，审核后再生成正式的 `canonical` 数据快照。这样既能保留两份原始数据，又能形成可追溯的最终数据。
