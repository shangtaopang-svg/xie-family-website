枫槎谢氏世系图 · 独立交付版

一、交付范围
本文件夹是独立交付界面，不属于原网站页面，也不会改动原网站的 pages、css、js、data 等目录。
界面中的卡片式树状布局参考了用户提供的示意图；本交付目录不再内置人物数据副本，页面运行时统一读取族谱管理后台的 canonical API。旧版 data.js 仅保存在项目备份中，不参与网站展示、编辑或查询。

二、打开方式
1. 双击 index.html，用现代浏览器打开即可。
2. 如果浏览器限制本地文件脚本，可将整个文件夹放在任意本地静态服务器下访问；不需要安装数据库或额外依赖。

三、主要功能
- 视图切换：总览、远古、申伯、始宁东山、临海下渡、石马（下谢）、本宗（下枫槎）七类世系图可分别查看。
- 点击人物卡片：查看完整详情、父母、配偶、子女、祖先路径和原始字段。
- 编辑人物：填写姓名、世代、支系、时间地点、父母、配偶、族谱记载、出处页码、备注等。
- 新增人物 / 新增子女：新增条目会自动生成新的 ID；新增子女可自动带入当前人物作为父亲参考。
- 搜索与筛选：支持按姓名、支系、记载关键词、世代查找。
- 展开主脉、展开全部、全部收起：控制中央树状图的显示范围。
- 在中央世系图的任意位置（包括人物卡片）按住拖动：平移整张画布；单击卡片才会打开详情。
- “全景”按钮会按整棵树的实际宽高自动缩小到可见范围；全景主要用于定位，点击“＋”可逐级放大查看局部。
- 鼠标滚轮可按指针位置缩放；默认使用紧凑卡片减少横向宽度，“标准”按钮可切回大卡片阅读文字。
- “展开全部”会自动切换紧凑全景，便于先看全貌，再用滚轮放大和拖拽平移阅读局部。
- 本宗世系图增加“本宗快速查看”：可直接聚焦撰（前枫槎）、攒（后枫槎）及东西房，也可按1代、3代、5代渐进展开；撰与攒两个区域以不同底色和粗框标识，便于在大图中快速辨认。
- 本宗世系图采用姓名简卡模式：卡片主体只显示人物姓名，出继、入继、兼祧保留为角标；世代、支系、亲属关系和族谱资料点击卡片后在详情栏查看。
- 本宗快捷栏采用安全分级展开；人物较多时“安全展开”默认先展开前5代，避免一次性生成上千张卡片导致浏览器卡顿。
- 云鸿之下的重复“大德”已合并为一人，保留后代“德戬”的父子关系及后枫槎西房标注。
- 中央工具栏可隐藏 / 显示左侧控制栏和右侧详情栏；左右栏边缘的分隔线可直接拖动调窄或调宽，布局偏好会保存在当前浏览器。
- 展开全部后可点击“隐藏界面”进入沉浸全景模式，隐藏顶部标题、提示条、工具栏、视图标签、支系导航、图例和底部状态栏；左上角“显示界面”或 Esc 可恢复。
- 出继 / 入继：卡片使用紫色“出继”标记和粉橙色“入继：某人”标记；重复的入继人物卡不重复绘制，出继者保留在亲生父亲支系，其子女及后代在本图归入承嗣父名下。人物详情同时保留原始父母关系和本图归属关系。
- 导入 JSON、导出 JSON：用于交付前后的数据交换和备份。

四、数据保存说明
编辑内容保存在当前浏览器的 localStorage 中，并同步写入一份自动备份；不会回写 PDF，也不会回写原网站数据文件。
每次编辑保存都会更新自动备份。仍建议每次批量修改后点击“导出 JSON”保存到电脑；更换浏览器或清理浏览器数据后，本地编辑内容和自动备份都可能消失，可用 JSON 重新导入。
点击“恢复原始数据”会清除当前浏览器中的编辑版本，恢复本交付包自带的数据；执行前建议先导出备份。
保存、删除、导入或恢复数据后，页面会原地重绘：保留当前世系图、缩放比例、平移滚动位置、展开层级和详情滚动位置，并立即显示最新内容，不需要重新进入页面。
打开人物详情后点击“直接编辑（实时保存）”，修改字段会自动写入当前浏览器并立即更新世系图卡片；编辑表单不会因为自动保存而重建，输入焦点和光标不会跳动。
本宗世系图中“文对”（ID 61）、“彬”（ID 60）、“乾”（ID 59）分别采用紫、青、珊瑚三种独立高亮色，便于识别三张重点卡片。
已校正人物关系：孟献（ID 47）的父亲为文用（ID 44）；宏基保留为其兼祧 / 祀承关系说明。
“彬”和“乾”的卡片底色分别固定为青绿色和珊瑚色；出继、入继及相关承嗣徽标统一固定在卡片左上角，不再占用人物主体内容区域。
“彬”和“乾”各自从本人卡片开始的后代区域，只保留青绿色、珊瑚色粗边框和区域标题；区域本身不再铺底色，人物卡片分别保持统一纯色底色。
彬及其后代人物卡片统一改为墨绿色底色，并使用浅色文字，保证在本宗全量展开时仍清晰可读。
左侧“展开全部”现在会展开当前视图中的完整世系（本宗视图为全本宗），先显示“展开中…”再生成全图，完成后自动缩小到全景，之后可继续滚轮缩放和平移。
全量展开观看已改为独立画布缩放：缩放使用鼠标位置作为中心，滚轮和平移按浏览器帧合并处理，减少大图拖动时的卡顿和跳动。
